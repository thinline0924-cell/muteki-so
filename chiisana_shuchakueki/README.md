# ちいさな終着駅

小さな列車を正しい線路へ導き、クリアするたびに小さな終着駅の町が育っていく、
スマートフォン向けの線路パズルです(Flutter 製。Android / iOS 向け)。

> このフォルダは、同じリポジトリの推理アドベンチャー「霧笛荘事件」とは**別のアプリ**です。

## いまの状態(Phase 2:ゲームとしての完成)

できること
- **50 ステージ**(5 つのワールド。5×5 → 6×6 → 7×7、十字線路・T字線路も登場)
- 線路をタップで回す、1手戻す、リセット、ヒント、出発。列車が線路にそって走り、失敗すると止まって理由を表示
- 星 1〜3 の評価とコイン(初回クリアボーナスあり)。合計の星で次のワールドが開く
- **進み具合の保存**(アプリを閉じても続きから遊べる。端末の中だけに保存)
- **町づくり**:お店でコインを使って建物・装飾を買い、駅前の 14 の区画に置く・片づける。置くほど町の名前が変わる
- **コレクション図鑑**:列車 6・駅舎 4・建物 6・装飾 7・住民 8。手に入れると知らせが出て、図鑑に NEW の印。
  選んだ列車がパズルで走り、選んだ駅舎が町に建つ
- **効果音と BGM**(自作の合成音)、振動、設定画面(音量・振動・データの保存について・プライバシーポリシー・利用規約・データを消す)
- **チュートリアル**:最初のステージは「指」で次にタップする線路を教え、つながったら出発ボタンを光らせる。
  新しい要素(カーブ・固定・障害物・十字・T字)が出るステージでは説明カード。町の画面でも最初に説明

まだできないこと(次の段階で作る)
- 広告・アプリ内課金(Phase 3)
- アプリアイコン・起動画面・ストア公開の準備(Phase 4)
- 機種変更のときのデータの引きつぎ

## 遊んでみる(Android)

パソコンに何も入れなくても、GitHub が自動で作った APK(Android アプリのファイル)で試せます。

1. GitHub のこのリポジトリで **Actions** タブを開く
2. 「ちいさな終着駅」のいちばん新しい実行(緑のチェック)を開く
3. 下の **Artifacts** から `chiisana-shuchakueki-apk` をダウンロードして zip を開く
4. 中の `app-release.apk` を Android 端末に送り、開いてインストールする
   (「提供元不明のアプリ」の許可を求められたら許可する。テスト用の署名なのでストアには出せません)

iPhone で試すには Mac と Xcode が必要です。

## 開発する

Flutter(3.47 以上)を入れたパソコンで:

```
cd chiisana_shuchakueki
flutter pub get
flutter test                 # 自動テスト
flutter run                  # つないだ端末やエミュレーターで起動
flutter run -d chrome        # ブラウザで起動
dart run tool/build_stages.dart   # ステージ JSON を作り直す
dart run tool/build_sounds.dart   # 効果音・BGM を作り直す
```

全ステージを開放し、町に建物を置いた状態で見た目を確かめたいときは
`flutter run -t tool/preview/main_preview.dart`(保存はされません)。

## 素材について

外部の画像・音声素材は使っていません(ライセンスの心配がない自作素材だけ)。

- 絵:すべてコード(`lib/ui/painters/`)で描いた仮素材
- 音:`dart run tool/build_sounds.dart` で波形を計算して作った wav(`assets/sounds/`)

外部の素材を使う場合は、商用利用とアプリ配布が許可されていることを確認し、
ライセンスをここに記録します。
