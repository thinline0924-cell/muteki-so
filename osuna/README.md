# 押すな。(DON'T TAP)

待つほど倍率が上がる。画面に出てくる誘惑を押したら全損。
本物のボーナスだけを見抜いて押し、ヒビが入る前に利確する、セピア色のチキンレースです。
ゲームデザイン書「押すな。ゲームデザイン書」をもとにした試作版です。

## 遊び方

- **待つ**:何もしなければ倍率が上がる(10秒で×2、30秒で×10、60秒で×50)
- **利確**:画面下の帯から上へスワイプ(パソコンは ↑キー)。その倍率で受け取って終了
- **ヒビ**:入ったら数秒以内に利確。間に合わないと全損
- **押すな**:出てくるものを押したら全損。本物のボーナスだけは押すと ×3
- **本物の見分け方**:「チリン」とネオン「大当り」の光が先に来て、そのすぐあとに音なしで出る(ステージが進むと見分け方が増える)

## ギャンブルの要素

- 賭け金(10 / 50 / 100 / 500 / 全部)を選んでから勝負する
- 勝ったら「倍プッシュ」:丁か半かで、当たれば倍・外せば0枚(3回まで)
- 「今日の一発」:全員同じ配置で1日1回。毎日「本物の見分け方」が1つ入れかわる

## 収益のしかけ(ブラウザ版はデモ表示)

| 種類 | 内容 | 出す場所 |
|---|---|---|
| ごほうび広告 | 全損したとき半分回収 / 本物を1回教えてもらう / 今日の配置で練習 / 破産から200枚 | 自分で選んだときだけ |
| 全画面広告 | 3回の勝負ごとに1回 | 勝負の外だけ(勝負中には絶対出さない) |
| 課金 | 広告をなくす ¥480 / テーマ ¥160 / シーズンパス(準備中) | 店・結果画面 |

`js/monetize.js` がその窓口です。アプリにしたとき、アプリ側が `window.OsunaNative` を用意すれば本物の広告・課金に切りかわります。

## App Store / Google Play に出すまで

このフォルダはそのままアプリの中身として使えます。アプリにする作業には次のものが要ります。

1. **包む道具**:Capacitor(カパシター。Webで作ったゲームをiPhone・Androidのアプリに包む道具)。Node.js が入ったパソコンが必要
2. **iPhone 版**:Mac と Xcode、Apple Developer Program(年 ¥12,980 前後)
3. **Android 版**:Android Studio、Google Play デベロッパー登録(初回 $25)
4. **広告**:AdMob(Google の広告)。`OsunaNative.showRewarded` などを AdMob につなぐ
5. **課金**:App Store / Google Play の課金(RevenueCat などの仲介サービスを使うと楽)
6. **ランキング**:Game Center / Google Play ゲーム サービス
7. **フォント**:今は Google Fonts をネットから読んでいる。アプリでは端末に同梱する

### 審査で気をつけること

- **年齢区分**:ゲーム内コインで賭ける「疑似ギャンブル」なので、レーティングは高め(Apple は 17+ 相当)になる見込み
- **コインは売らない**:お金でコインを買えて賭けられると、ギャンブル扱いの審査が厳しくなる。今の設計では課金は「広告削除」と「見た目」だけ
- **ニセ通知・ニセエラー**:iOS / Android 本物の通知やダイアログに見えない、ゲーム内の手描きデザインにしている
- **広告**:勝負中には出さない。誘惑に広告の「×」や「広告」表記をまねたものは使わない
- **点滅**:起動時に注意を出し、設定に「点滅をへらす」がある
- 申請前に、最新の App Store 審査ガイドラインと Google Play デベロッパー ポリシーを確認する
