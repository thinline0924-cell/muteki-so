# 押すな。(DON'T TAP)

倍率は少しずつ上がり、壁の「運命スロット」が勝手に回ってそろうたびに跳ね上がる。ドクロが3つ出たら全損(賭けた枚数が0)。
画面に出てくる誘惑も押したら全損。本物のボーナスだけを見抜いて押し、割れる前に受け取る、セピア色のチキンレースです。
ゲームデザイン書「押すな。ゲームデザイン書」をもとにした試作版です。

## 遊び方

ゲームの中にも、絵が動く「遊び方」(7ページ)があります。はじめて勝負する前に自動で出て、ホームの「遊び方」からいつでも見られます。ステージ1では勝負中に「ヒント」の字幕も出ます。

- **待つ**:倍率が少しずつ上がる(30秒で約×2.5)
- **受け取る**:画面下の帯から上へスワイプ(パソコンは ↑キー)。その倍率で受け取って終了
- **運命スロット**:勝負中ずっと勝手に回って止まる。3つそろうと倍率アップ(チェリー×1.5 / ベル×2 / BAR×3 / 7×7)+5秒の「フィーバー」(倍率が2.5倍の速さで上がる)。左2つそろいは+10%
- **ドクロ**:出るたびにヒビが1本。3本で全損。あと1本の時は「リーチ」でリールがゆっくり止まる。受け取って逃げるか、賭けて待つか。くぐり抜けたら×1.2。ドクロは時間がたつほど出やすくなる
- **押すな**:出てくるものを押したら全損。本物のボーナスだけは押すと ×3
- **本物の見分け方**:「チリン」とネオン「大当り」の光が先に来て、そのすぐあとに音なしで出る(ステージが進むと見分け方が増える)

## ギャンブルの要素

- 賭け金(10 / 50 / 100 / 500 / 全部)を選んでから勝負する
- 勝負中のスロット:そろう・7が2つで「777チャンス」・ドクロのリーチ。毎回の止まり方が賭けになる
- 受け取り額が賭け金の3倍以上で「BIG WIN」、5倍以上「MEGA WIN」、10倍以上「超大当り」の演出
- 「今日の配給」は1日1回の無料スロット(777で3,000枚 / 3つそろいで1,000枚 / 2つで500枚 / それ以外200枚)
- 勝ったら「倍か0か」:丁(偶数)か半(奇数)かで、当たれば倍・外せば0枚(3回まで)
- 「今日の一発」:全員同じ配置で1日1回。毎日「本物の見分け方」が1つ入れかわる

## 収益のしかけ(ブラウザ版はデモ表示)

| 種類 | 内容 | 出す場所 |
|---|---|---|
| ごほうび広告 | 全損したとき半分回収 / 本物を1回教えてもらう / 今日の配置で練習 / 破産から200枚 | 自分で選んだときだけ |
| 全画面広告 | 3回の勝負ごとに1回 | 勝負の外だけ(勝負中には絶対出さない) |
| 課金 | 広告をなくす ¥480 / テーマ ¥160 / シーズンパス(準備中) | 店・結果画面 |

`js/monetize.js` がその窓口です。アプリにしたとき、アプリ側が `window.OsunaNative` を用意すれば本物の広告・課金に切りかわります。

## 画面

背景はいつも動いています(窓の外のサーチライト・雲・飛行機・またたく窓明かり・電車・車、揺れるカーテン、光の中のほこり、灰皿の煙、テレビの競馬中継、壁のスロットの電球)。


タイトル(タップではじめる)→ **ホーム** → ステージ選択と賭ける枚数 → 勝負 → 結果。
ホームには、手持ちの枚数、いまの格(クリア数で変わる)、今日の配給スロット(1日1回)、つづきのステージ、今日の一発、遊び方があります。下のタブで ホーム / ステージ / 一発 / 店 / 記録 を行き来します。

## BGM(曲ファイル)

`js/bgm-data.js` を置くと、合成の曲のかわりにその曲が流れます。中身は `window.OSUNA_BGM = { loopStart: 秒, loopEnd: 秒, data: 'MP3をbase64にした文字' }` だけです。
前奏を1回流したあと、loopStart〜loopEnd をつなぎ目なしでくり返します。勝負中は曲がこもって小さくなり、その上に心音が重なります。
曲を文字(base64)にして JS に入れているのは、`index.html` をダブルクリックで開いた時(file://)でも読めるようにするためです。
ファイルを置いたら、`index.html` の `js/sound.js` の行の前に `<script src="js/bgm-data.js"></script>` を足します。

**Suno の曲を使うとき**:無料プランで作った曲は商用利用できません。ストアで広告・課金つきで出すなら、有料プラン(Pro / Premier)に入っている間に作った曲を使ってください(最新の規約も確認してください)。

## App Store / Google Play に出すまで

このフォルダはそのままアプリの中身として使えます。アプリにする作業には次のものが要ります。

1. **包む道具**:Capacitor(カパシター。Webで作ったゲームをiPhone・Androidのアプリに包む道具)。Node.js が入ったパソコンが必要
2. **iPhone 版**:Mac と Xcode、Apple Developer Program(年 ¥12,980 前後)
3. **Android 版**:Android Studio、Google Play デベロッパー登録(初回 $25)
4. **広告**:AdMob(Google の広告)。`OsunaNative.showRewarded` などを AdMob につなぐ
5. **課金**:App Store / Google Play の課金(RevenueCat などの仲介サービスを使うと楽)
6. **ランキング**:Game Center / Google Play ゲーム サービス
7. **フォント**:今は Google Fonts をネットから読んでいる。アプリでは端末に同梱する

### 審査で気をつけること

- **年齢区分**:ゲーム内コインで賭ける「疑似ギャンブル」なので、レーティングは高め(Apple は 17+ 相当)になる見込み
- **コインは売らない**:お金でコインを買えて賭けられると、ギャンブル扱いの審査が厳しくなる。今の設計では課金は「広告削除」と「見た目」だけ
- **ニセ通知・ニセエラー**:iOS / Android 本物の通知やダイアログに見えない、ゲーム内の手描きデザインにしている
- **広告**:勝負中には出さない。誘惑に広告の「×」や「広告」表記をまねたものは使わない
- **点滅**:起動時に注意を出し、設定に「点滅をへらす」がある
- 申請前に、最新の App Store 審査ガイドラインと Google Play デベロッパー ポリシーを確認する
