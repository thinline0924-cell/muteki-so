# 夜光区 — NEON DISTRICT

雨の止まないサイバー市街で戦う、ブラウザの FPS(一人称シューティング)です。
**パソコンに何も入れなくても遊べます。** `neon-fps/index.html` をダブルクリックするだけ(Chrome / Edge / Firefox / Safari の新しい版)。

- 絵: 自作の WebGL2 レンダラーで、その場で街を描きます(画像ファイルなし)
- 音: 銃声・足音・雨・BGM まで、すべて Web Audio でその場で合成します(音声ファイルなし)
- 画面: 参考画像の「こげ茶の線画+クリーム色の紙」の雰囲気。メニューを開くと街もイラスト調になります

|---|---|

スマホ・タブレットでは画面のボタンとスティックで遊べます(横向き推奨)。

## 飽きないためのしくみ

- **区画(ステージ)は毎回自動生成**: 道・ビル・路地・屋台・工事現場・高架・ジャンプ台の配置と、街の色(4テーマ)が変わる
- **3つの波 → 改造チップ → 店**: 波を越えるたびに 28 種類の改造チップから1つ選ぶ(二段ジャンプ・跳弾・過充電弾・相棒ドローン など)。区を制圧すると闇市で武器や強化を買える
- **波の種類**: 殲滅 / 制圧(端末のそばにとどまる)/ 回収(印の敵がデータコアを落とす)/ 精鋭狩り / ボス戦(鬼神 ONI-零式)
- **区のしかけ**(第2区から): 低重力・豪雨・狂騒・装甲化・首狩り・停電・爆発祭り
- **強化個体(エリート)**: 装甲・俊足・爆裂・分裂・再生
- **依頼**: 区ごとのおまけ目標(刀で5体、空中で5体 など)。達成すると報酬
- **評価 D→C→B→A→S→SS→極**: 続けて倒す・ヘッドショット・空中・スライディング・弾き返しで上がり、得点倍率が上がる
- **武器の解放**: レールガン(第2区到達)、アークガン(通算150体)、ロケット(第3区到達)、ニードラー(通算40ヘッドショット)
- **今日の街**: 日付で決まる同じ街・同じしかけで、だれとでも得点を比べられる
- 記録・設定(感度・視野角・音量・画質・イラスト調で遊ぶ)はブラウザに保存されます

## 武器

| 名前 | 種類 | 戦い方 |
|---|---|---|
| P-9 ハチドリ | ハンドガン | 弾数無限。頭を狙えば強い |
| SMG スズメバチ | サブマシンガン | 走りながら近距離を制圧 |
| AR カラス | アサルトライフル | 覗けば遠距離も届く万能銃 |
| SG イノシシ | ショットガン | スライディングで飛びこんで一撃 |
| レールガン サギ | 電磁砲 | ためて撃つ。並んだ敵を貫く |
| アークガン ホタル | 電撃 | 弾切れなし。近くの敵へ飛び移る(熱に注意) |

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み(スクリプトを順に読みこむ) |
| `css/style.css` | HUD・メニューの見た目(線画+クリーム色、スマホ対応) |
| `js/math.js` | ベクトル・行列・シード付き乱数・当たり判定の計算 |
| `js/gl.js` | WebGL2 レンダラー(街・部品・光の粒・空・濡れた路面の映りこみ・ブルーム・イラスト調仕上げ) |
| `js/tex.js` | 壁・看板・路面などの絵をその場で描く |
| `js/city.js` | 区画の自動生成と、敵の通り道(経路探索) |
| `js/sfx.js` | 効果音・環境音・BGM の合成 |
| `js/weapons.js` | 武器のデータ・撃ち方・手に持った武器の見た目 |
| `js/enemies.js` | 敵の種類・行動・見た目 |
| `js/fx.js` | 火花・爆発・煙・雨・弾道・弾痕・飛び散る部品 |
| `js/ui.js` | HUD・メニュー・レーダー・タッチ操作 |
| `js/game.js` | 進行(プレイヤーの動き・戦闘・波・改造・店・保存・描画のまとめ) |
