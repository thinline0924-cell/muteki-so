# CLAUDE.md — 夜窓ピンボール(pinball/)の設計指針

スマホ縦画面向けの「物理ローグライト・ピンボール」。Vite + TypeScript(vanilla-ts 構成)。
持ち主はプログラミング初心者。**説明は日本語で、専門用語には短い説明を付ける。**

> このフォルダはリポジトリ直下の推理ゲーム「霧笛荘事件」とは別プロジェクト。
> 直下の CLAUDE.md の「ビルドツールを入れない」はあちら専用のルールで、ここでは Vite を使う。
> 逆に、ここで入れた npm の仕組みを直下のゲームに持ち込まないこと。

## 動かし方
- `npm install` → `npm run dev`(開発サーバー。既定は http://localhost:5173)
- `npm run build`(= `tsc && vite build`)が**エラー 0 で通る状態を常に保つ**。出力は `dist/`

## 絶対ルール
1. **外部アセット完全禁止。** 画像(PNG/JPG/SVG ファイル)・音声(MP3/WAV)・Web フォントを読み込まない
   - 絵はすべて Canvas 2D の図形・グラデーション・発光(shadowBlur / 'lighter' 合成)で描く
   - 音はすべて Web Audio API(OscillatorNode / GainNode / BiquadFilterNode)でその場で合成する
2. **縦画面 9:16 固定。** 論理解像度は 540×960(`src/game/constants.ts` の W/H)。
   PC では画面中央にスマホ枠として表示し、リサイズに追従する。DOM の UI は CSS 変数 `--u`(=枠の幅/540)で拡大縮小する
3. **タッチとマウスの両対応。** 盤面をドラッグで狙う → 反射予測の点線 → 指を離して発射
4. **見た目のトーン**: 参考画像(夜の部屋の線画イラスト)に寄せる。
   オリーブ/カーキの壁、こげ茶の線(インク)、クリーム色のハイライト、夜の窓=盤面。
   ペグやエフェクトだけがネオンで光る(通常=クリーム白、分裂=水色、爆発=赤、倍率=黄、電撃=紫)。
   参考画像そのものを写さない(雰囲気だけ借りる)
5. 乱数は `Math.random` で良い(このゲームは再現性を求めない)
6. 課金・広告は**すべてモック**。本物の決済や広告 SDK を入れない。モックであることを画面に明記する

## ゲーム仕様(要約)
- **ペグ**: 通常(耐久1〜3) / 分裂(水色・ボール分裂) / 爆発(赤・範囲巻き込み、連鎖) /
  倍率バンパー(黄・強く弾き、そのショットの総ダメージに ×1.5 / ×2.0) / 電撃(紫・近くの 3〜5 個へ連鎖)
- **ショット**: 全ボールが下に落ちたら、そのショットの総ダメージを敵に与える。敵の HP を削り切れば Wave クリア
- **敵**: HP バーと攻撃カウントダウン(壁掛け時計)。0 になるとプレイヤーを攻撃
- **ローグライト**: Wave クリアごとに強化カード 3 択(`src/game/Upgrades.ts`、12 種類以上)
- **JuiceManager**(爽快感の司令塔): 音階が上がるコンボ SE / ヒットストップ・スロー / 減衰するカメラシェイク /
  ネオン火花 20〜40 個 / 弾け飛ぶ文字 / 50 コンボでフィーバー(背景の脈動+虹色の軌跡)
- **MonetizationManager**(モック): リワード広告(2 秒のオーバーレイ)= 引き直し / ボール 2 倍ブースト / コンティニュー。
  ¥600 パス(広告削除+2x・3x 解放)。コインで永続強化(メタ育成)
- **🛠️Debug**: ボール 20 個即発射 / 全ペグを分裂&爆発化 / コイン +10,000 / 次 Wave へ

## ファイル
| ファイル | 役割 |
|---|---|
| `index.html` | 入口。`#app` だけ置く |
| `src/main.ts` | 起動 |
| `src/style.css` | スマホ枠・DOM の UI(ボタン・モーダル)の見た目 |
| `src/game/constants.ts` | 画面サイズ・盤面の範囲・物理定数・色 |
| `src/game/Game.ts` | 司令塔。状態遷移(タイトル→狙う→ショット中→集計→敵の番→カード選択→ゲームオーバー)とメインループ |
| `src/game/Physics.ts` | ボール・ペグの型、円の衝突と反射、空間グリッド(当たり判定の高速化) |
| `src/game/BoardGen.ts` | 盤面(ペグ配置)の生成 |
| `src/game/JuiceManager.ts` | 演出(パーティクル・文字・揺れ・ヒットストップ・フィーバー) |
| `src/game/AudioEngine.ts` | 効果音と BGM の合成 |
| `src/game/Renderer.ts` | Canvas への描画(背景の部屋・ペグ・ボール・敵・照準) |
| `src/game/sketch.ts` | 手描き風の線を引く小道具 |
| `src/game/Enemies.ts` | 敵の種類・強さ・絵 |
| `src/game/Upgrades.ts` | 強化カード(ラン中のステータス) |
| `src/game/Save.ts` | localStorage への保存(コイン・永続強化・購入状態) |
| `src/game/MonetizationManager.ts` | 広告・課金のモック |
| `src/ui/UI.ts` | DOM の UI(上部バー・モーダル・デバッグパネル) |

## 変更したら確かめること
- `npm run build` がエラー 0
- 何 Wave か遊んで、カード選択・敵の攻撃・ゲームオーバー→コンティニューまで通る
- 2x / 3x で物理が破綻しない(固定ステップ 1/200 秒を回数で増やしている)
- ボールが数百個でもカクつきすぎない(上限 `MAX_BALLS`、パーティクル上限あり)
