# CLAUDE.md — 夜窓ピンボール(pinball/)の設計指針

スマホ縦画面向けの「物理ローグライト・ピンボール」。Vite + TypeScript(vanilla-ts 構成)。
持ち主はプログラミング初心者。**説明は日本語で、専門用語には短い説明を付ける。**

> このフォルダはリポジトリ直下の推理ゲーム「霧笛荘事件」とは別プロジェクト。
> 直下の CLAUDE.md の「ビルドツールを入れない」はあちら専用のルールで、ここでは Vite を使う。
> 逆に、ここで入れた npm の仕組みを直下のゲームに持ち込まないこと。

## 動かし方
- `npm install` → `npm run dev`(開発サーバー。既定は http://localhost:5173)
- `npm run build`(= `tsc && vite build`)が**エラー 0 で通る状態を常に保つ**。出力は `dist/`

## 絶対ルール
1. **外部アセット完全禁止。** 画像(PNG/JPG/SVG ファイル)・音声(MP3/WAV)・Web フォントを読み込まない
   - 絵はすべて Canvas 2D の図形・グラデーション・発光(shadowBlur / 'lighter' 合成)で描く
   - 音はすべて Web Audio API(OscillatorNode / GainNode / BiquadFilterNode)でその場で合成する
2. **縦画面 9:16 固定。** 論理解像度は 540×960(`src/game/constants.ts` の W/H)。
   PC では画面中央にスマホ枠として表示し、リサイズに追従する。DOM の UI は CSS 変数 `--u`(=枠の幅/540)で拡大縮小する
3. **タッチとマウスの両対応。** 盤面をドラッグで狙う → 反射予測の点線 → 指を離して発射
4. **見た目のトーン**(持ち主の指摘で作り直した。「チープ・AIっぽい」と言われた反省):
   - 古い印刷物のような**紙(クリーム)+インク(こげ茶)+赤**。赤は危険・強調(ヒビ、やられた、クリティカル)だけ
   - 角はほぼ四角(2〜4px)。影はぼかさず「ずらしたインクの板」。**絵文字・丸いピル型ボタン・色の帯つきカード・多色ネオンは使わない**
   - 文字は角ばった極太ゴシック、数字は幅広の極太体(端末内蔵の書体のみ)。大きな数字はクリーム白でぼんやり光らせる
   - 上下に細い暗い帯、小さな文字で情報を出す。告知は「白い極太文字+紙のタグ」「紙のカード」「赤いハンコ」の3種
   - ペグの色(水色・赤・黄・紫)は彩度を落とす。画面全体にビネットとセピアの色かぶせ(`.vignette` `.tint`)
   - **砂嵐のような粒子ノイズは入れない**(プレイの邪魔になると持ち主に言われて外した)
   - 参考画像そのものを写さない(雰囲気だけ借りる)
   - **キャラクターは出さない**(持ち主の指示で削除した)
   - **タイトル画面は余白を大事に**:ペグを描かず夜の窓だけ。縦に積んだ題字「夜窓」と、文字と細線だけのメニュー。
     説明文・凡例・キャッチコピー・箱を並べたメニューなど「全部入り」にしない(AI っぽいと言われた)
   - 紙のシートやカードを傾ける、などの「手作り風の小細工」はしない。まっすぐ置いて落ち着かせる
   - 縦書きは CSS の writing-mode に頼らず 1 文字ずつ積む(端末によって崩れるため)。長音「ー」は回転させる
5. 乱数は `Math.random` で良い(このゲームは再現性を求めない)
6. 課金・広告は**すべてモック**。本物の決済や広告 SDK を入れない。モックであることを画面に明記する

## ゲーム仕様(要約)
- **目的はハイスコア**(敵・HP は無い)。スコアが「ライン」(500 から 2.4 倍ずつ、`lineTarget()`)を越えるたびに強化カード 3 択
- **プレイモード**(`src/game/Modes.ts`):
  - 一晩 … 12 ショット(+永続強化「夜の長さ」)。3 ライン毎にショット +1。基本のモード
  - 今夜の一局 … 日付の種(`rng.ts`)で盤面とカードが全員同じ。永続強化なし・延長なし。自己ベストは日付ごと
  - 九十秒 … 玉が動いている間だけ時間が減る(倍速でも公平になるようゲーム内時間で数える)
  - 三球勝負 … ボール +4 個で 3 ショットだけ
  - 自己ベストはモードごと(`save.bests`)
- **バランスの約束**(永続強化 MAX でもゲームが壊れないように。持ち主の指摘で直した):
  - 盤面が空にならない:先のラインほど固いペグ(耐久 2〜5)が増える/爆発は 2 ずつ削る/
    壊れた通常ペグはショット中でも約 3 秒で灯り直す(特殊ペグは灯り直さない。4 割を切ったら盤面入れ替え)
  - 倍率バンパーは 1 ショットに 3 回まで(下の点が残り回数。使い切ると暗くなる)
  - コンボの上乗せは 120 コンボで頭打ち
  - ショットが増えすぎない:ライン突破のショット +1 は 3 本毎だけ。夜ふかしは +2・レア・2 回まで
  - 永続強化の上限:攻撃 Lv10・ボール Lv2・夜の長さ Lv5(超えていた分は読み込み時にコインで返す)
  - 確かめ方:永続強化 MAX で自動プレイし、ショット数が減っていくこと・盤面が空のまま終わるショットがほぼ無いことを見る
- **遊び方**(`src/ui/Tutorial.ts`):絵つき 4 ページ(狙い方 / ペグの種類 / スコアとライン / 夜明け)。絵は Canvas で描く。
  はじめてタイトルでモードを選んだときに自動で開き、閉じるとそのまま始まる。以後はタイトルの「遊び方」から見られる。
  「次回もゲーム開始時に表示する」で自動表示を切り替え(`save.howto`:first / on / off)
- **窓の外の風景**:奥の街(低く薄い)と手前の街(チョークの線画、屋上に給水塔・アンテナ・空の看板枠)、電線、流れる薄い雲、
  塔の赤い点滅灯、夜はときどき流れ星、夜明けには鳥。**背景に文字(看板の文字など)は入れない**
- **遊びやすさ**(リリース後に来そうなレビューを先回りして直した):
  - 一時停止:上の帯のボタン(遊んでいる間は縦 2 本線、タイトルでは「設定」)。Esc / P キーでも。別アプリに切り替えると自動で一時停止
  - 設定(`save` の bgm / sfx / vibe / calmFx / saver):BGM と効果音は別々に切れる/振動/演出を控えめに(揺れ 3 割・フラッシュ 35%)/
    省電力(30fps・解像度 1 倍・軽い演出)
  - 続きから:ショットとショットの間の状態を `save.run` に保存。タイトルの一番上に「続きから」。
    撃ったあと結果が出る前に閉じたら、そのショットは 0 点として数える(撃ち直しのずる防止)。夜明けで消す。今夜の一局は日付が変わると無効
  - 誤発射防止:10px 未満しか動かさず 0.18 秒未満で離したら撃たない(狙いだけ合わせて案内を出す)
  - 長いショットは 10 秒を過ぎると最大 3 倍まで自動で早送り(右上に「早送り」の札)
  - 2x は無料、3x だけパス特典
- **ペグ**: 通常(耐久1〜5) / 分裂(水色・ボール分裂) / 爆発(赤・範囲巻き込み、連鎖) /
  倍率バンパー(黄・強く弾き、そのショットのスコアに ×1.5 / ×2.0) / 電撃(紫・近くの 3〜5 個へ連鎖)
- **ショット**: 全ボールが下に落ちたら、そのショットのスコアが合計に入る(光の玉が壁のスコアへ飛ぶ)
- **夜明けの空**: 使ったショットの割合(`Game.nightP`)で窓の外が変わる。星と月が消え、地平線から温かい光、
  建物は影になり、窓の明かりが半分ずつ消え、最後の 3 割で太陽が昇る(`Renderer.drawSky`)。延長すると夜に少し戻る。
  BGM も少しずつ明るくなり、夜明け前は鳥が鳴く。ペグが読めるよう、空は明るくしすぎない
- **ローグライト**: ライン突破ごとに強化カード 3 択(`src/game/Upgrades.ts`、22 種類)
- **JuiceManager**(爽快感の司令塔): 音階が上がるコンボ SE / ヒットストップ・スロー / 減衰するカメラシェイク /
  火花 20〜40 個 / 弾ける文字 / 50 コンボでフィーバー(背景の脈動+虹色の軌跡、スコア ×1.5)
- **MonetizationManager**(モック): リワード広告(2 秒のオーバーレイ)= 引き直し / ボール 2 倍ブースト / 延長(一晩はショット +3・九十秒は +20 秒・三球は +1、全ペグ誘爆つき、1 回だけ)。
  ¥600 パス(広告削除+3x 解放。2x は無料)。コインで永続強化(メタ育成)
- **🛠️Debug**: ボール 20 個即発射 / 全ペグを分裂&爆発化 / コイン +10,000 / 次のラインへスキップ / ショット +5(九十秒は +20 秒)

## ファイル
| ファイル | 役割 |
|---|---|
| `index.html` | 入口。`#app` だけ置く |
| `src/main.ts` | 起動 |
| `src/style.css` | スマホ枠・DOM の UI(ボタン・モーダル)の見た目 |
| `src/game/constants.ts` | 画面サイズ・盤面の範囲・物理定数・色 |
| `src/game/Game.ts` | 司令塔。状態遷移(タイトル→狙う→ショット中→スコア集計→ライン突破→カード選択→夜明けの結果)とメインループ |
| `src/game/Physics.ts` | ボール・ペグの型、円の衝突と反射、空間グリッド(当たり判定の高速化) |
| `src/game/BoardGen.ts` | 盤面(ペグ配置)の生成 |
| `src/game/JuiceManager.ts` | 演出(パーティクル・文字・揺れ・ヒットストップ・フィーバー) |
| `src/game/AudioEngine.ts` | 効果音と BGM の合成。ガラス/ベル音は FM 合成、部屋の響き(リバーブ)はノイズから作った響きデータ |
| `src/game/Renderer.ts` | Canvas への描画(背景の部屋・ペグ・ボール・敵・照準) |
| `src/game/sketch.ts` | 手描き風の線を引く小道具 |
| `src/game/Upgrades.ts` | 強化カード(ラン中のステータス)と永続強化の上限 |
| `src/game/Modes.ts` | プレイモードの定義(ショット数・時間・永続強化を使うか など) |
| `src/game/rng.ts` | 乱数(今夜の一局だけ日付の種つき) |
| `src/game/Save.ts` | localStorage への保存(コイン・永続強化・購入状態) |
| `src/game/MonetizationManager.ts` | 広告・課金のモック |
| `src/ui/Tutorial.ts` | 遊び方(絵つき 4 ページ)。初回の自動表示と、表示のオン・オフ |
| `src/ui/UI.ts` | DOM の UI(上部バー・モーダル・デバッグパネル) |

## 変更したら確かめること
- `npm run build` がエラー 0
- 一晩遊んで、ライン突破→カード選択→夜明けの結果→夜の延長まで通る
- 一時停止 → 再開、途中で閉じて「続きから」が通る
- 2x / 3x で物理が破綻しない(固定ステップ 1/200 秒を回数で増やしている)
- ボールが数百個でもカクつきすぎない(上限 `MAX_BALLS`、パーティクル上限あり)
