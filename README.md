# 霧笛荘事件 ― ひと晩の推理録

昭和53年、霧の夜の灯台で起きた殺人事件を、朝6時までに解く推理アドベンチャーです。
**事件は毎回、自動で組み立てられます。** 1事件のプレイ時間はおよそ40〜60分です。

## 毎回ちがう事件になるしくみ

ゲームを始める前の「事件の準備」画面で、登場人物を自分で決められます。

- 探偵(あなた)と依頼人の名前
- 霧笛荘の5人の名前・性格(話し方が変わる)・職業(医者/画家/不動産業者/作家/新聞記者)・依頼人との関係
- 事件番号・難しさ・第二の事件のあり/なし

事件番号をもとに、次のものが毎回ちがう組み合わせで決まります(犯人はプレイヤーにも分かりません)。

- 犯人(5人のだれか)と動機(復讐・遺産・使いこみ・偽造・二十年前の罪)
- 時刻のトリック(霧笛の仕掛け/検死の偽り/なし)と、閂のかかった灯室からの脱出方法(外梯子/閂の糸/灯室に隠れる)
- 凶器と、その捨て場所・手袋や糸の持ち主
- 目撃者とその隠しごと、崖の上から灯室を見ていた人、脅迫状を書いた人
- 夜中の出来事の時刻と、第二の事件でねらわれる人
- 二十年前の夜の真相と、エンディング

同じ事件番号なら同じ事件になるので、友だちと番号を教え合って同じ事件を解くこともできます。
解決したあとは「事件の真相を見る」で、その事件の答え合わせができます。

## あそびかた

- **調べる**:画面の気になる所をクリック(または下の「調べる」ボタン)
- **話す**:その場にいる人に話を聞きます。手がかりが増えると話題も増えます
- **移動**:屋敷の中や外へ
- **手帳**:集めた証拠品・人物・キーワード・時系列を見られます
- **推理する**:捜査を終えて、推理(穴うめ)→ 犯人の名指し → 対決(証拠をつきつける)へ

行動するたびに時間が進みます。人は時刻によって居場所を変え、時刻によって出来事が起こります。
何をいつ調べたか、誰をかばったか、誰に何を伝えたかで、結末が変わります。
進み具合はブラウザに自動で保存され、タイトルの「つづきから」で再開できます。

## 遊ぶ方法(パソコンに何も入れなくてOK)

このリポジトリは、HTML・CSS・JavaScript だけでできています。
サーバーもビルドも要りません。音楽と効果音もすべてプログラムで作っているので、音のファイルもありません。

- **いちばん簡単**:GitHub の「Code」→「Download ZIP」でダウンロードして展開し、`index.html` をダブルクリック(Chrome / Edge / Safari)
- **ネットで公開する(Render の静的サイト)**
  1. Render で「New +」→「Blueprint」を選び、このリポジトリを選ぶ(`render.yaml` の設定が読みこまれます)
  2. 「Apply」を押すと、数分で URL ができます
  - Blueprint を使わない場合は「New +」→「Static Site」で、Build Command は空欄、Publish Directory に `.` と入力

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `css/style.css` | 見た目(灰緑と白と赤の配色、スマホ縦向きにも対応) |
| `js/scenario.js` | 事件ジェネレーター(事件番号と人物設定から、物語・手がかり・会話・出来事・推理・対決・エンディングを組み立てる) |
| `js/game.js` | 進行のしくみ(タイトル・事件の準備・文章表示・選択肢・時間・セーブ・推理・対決) |
| `js/pixel.js` | ドット絵(全場面・人物の顔・立ち姿)をその場で描く |
| `js/audio.js` | BGM 11曲・環境音・効果音をその場で合成する(Web Audio) |

# 霧走 MUSOU ― Prototype Racing(`race/` フォルダ)

同じリポジトリに入っている、もうひとつのゲームです。プロトタイプカー(ル・マンなどを走る耐久レース用の車)を操る **3DCG レースゲーム** です。

- **遊び方**:`race/index.html` をダブルクリック(Chrome / Edge / Safari)。Render で公開した場合は `https://(あなたのURL)/race/` で開けます
- **操作**:キーボード。↑/W アクセル、↓/S ブレーキ、←→/A D ハンドル、E/Q シフト(MT時)、Space ブースト、C カメラ、T テレメトリー、H 表示切りかえ、R コース復帰、Esc ポーズ
- **モード**:タイムアタック(ゴーストつき)/ レース(ライバル0〜7台、周回数・強さを選べる)

## マシン(実車がモチーフの架空の車)

| 名前 | モチーフ | 特徴 | メーター |
|---|---|---|---|
| KESTREL 962C | Porsche 962C(1986) | 水平対向6気筒ツインターボ。ターボの遅れ(ラグ)がある | 白い文字盤の針メーター |
| RV-4R 787 | Mazda 787B(1991) | 4ローター。9000回転まで回る甲高い音 | 緑と琥珀の LED バーグラフ |
| AURORA 919H | Porsche 919 Hybrid(2017) | V4ターボ+前輪モーターの4輪駆動。最速 | ハンドルの液晶+シフトライト |
| SOLSTICE 040 | LMH ハイパーカー(GR010 / 499P 世代) | V6ツインターボ+前輪モーター(160km/h から) | 弧を描くセグメント式タコメーター |

## コース(実在のサーキットがモチーフ)

| 名前 | モチーフ | 時間・天気 |
|---|---|---|
| MT. FUJI SPEEDWAY | 富士スピードウェイ | 朝・霧(富士山が見える) |
| ARDENNES CIRCUIT | スパ・フランコルシャン | くもり・霧(高低差70m) |
| PARCO VELOCE | モンツァ | 午後・晴れ |
| CIRCUIT DE LA BRUME | ル・マン(サルト・サーキット) | 夕暮れ(1周 約8.6km) |

## しくみ(かんたんに)

- **3D の絵**:three.js(3D を描くための有名な無料ライブラリ)を `race/js/lib/` に同梱。ネットにつながっていなくても動きます
- **画像・音声ファイルは使っていません**。車体の塗装・アスファルト・木などの模様はキャンバスに描いて作り、エンジン音は「排気の1発1発の波形」を合成して作っています
- **車の動き**:タイヤ4本それぞれの荷重(重さのかかり方)・すべり角・摩擦円(タテとヨコの力の合計に上限がある、というタイヤの性質)、空気抵抗とダウンフォース(速いほど車が路面に押しつけられる力)、ターボのラグ、ハイブリッドの充電と放出を、1秒に120回計算しています
- キーボードでも走りやすいように、ステアリング補助・TCS(空転防止)・ABS(ロック防止)・姿勢制御があります(設定で切れます)
